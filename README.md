# FOMO 交易看板（Chrome 扩展）

一个展示 FOMO（fomo.family）交易数据的浏览器看板扩展：**排行榜 / 跟单信号 / 热门代币 / 交易动态**，数据来自官方 API。

## 功能

- 📊 **排行榜**：Top50 交易者（关注者、交易数、总交易额、24h盈亏、**持仓代币**），15 秒刷新
- 📡 **跟单信号**：实时交易动态流（谁在买什么、发什么观点，**评论自动翻译成中文**），15 秒刷新
- 🔥 **热门代币**：**WebSocket 实时推送**（连接 `wss://prod-api.fomo.family/ws`，订阅 `trending_tokens` 全链 topic），价格/涨跌/成交额/市值秒级更新
- 🗞 **交易动态**：Feed 流（集体买入/卖出、新币上线、暴涨）
- 🔍 **搜索**：支持三种输入，自动识别
  - **代币地址(CA)** → 代币概览（价格/市值/买卖比/流动性）+ 💬 大家怎么说（观点讨论，**评论自动翻译成中文**，含作者当前持仓与盈亏）+ 👥 Top 持有者（谁在买/拿，含持仓数量/市值/盈亏）+ 📈 最近动态
  - **钱包地址** → 匹配这是 FOMO 上的谁（扫描排行榜各周期 + 近期交易者 + **地址反查索引**，返回用户名/粉丝/交易数/盈亏）
  - **用户名** → 用户模糊搜索
- 🌐 **评论翻译**：搜索代币的"大家怎么说"、最近动态评论、跟单信号评论，只要含英文就自动翻译成中文（虚线框显示译文，原文保留）；纯中文/纯数字不请求翻译
- 👤 **用户详情抽屉**：点击任意排行榜用户 / 跟单信号 / 搜索结果中的用户卡片，右侧滑出详情面板
  - 基本信息（头像/昵称/简介/标签）+ 数据总览（粉丝/交易数/交易额/24h盈亏/持仓币种）
  - **钱包地址**：完整展示 + 📋 一键复制 + 🔗 链上浏览器跳转（Solana/EVM）
  - **持仓代币**：当前持仓（数量/链/市值/盈亏）
  - **交易记录**：最近 15 笔，点击展开链上明细（开平仓均价/盈亏/Swaps 执行地址/链上转账/评论）
  - **链上活动地址**：该用户在交易中出现过的所有实际链上地址（交易账户 / Swap 执行 / 转账），跨 Solana、Base、BSC、ETH、Robinhood、Monad
- 🔎 **地址反查**：自动索引所有浏览过的用户的 绑定地址、交易账户地址、Swap 实际执行地址、链上转账地址；搜索任一地址即可命中"这是 FOMO 上的谁"
  - 专门解决 **FOMO 上买东西的地址 ≠ 真实钱包地址** 的问题（例如 EVM 撮合、Robinhood 链、BSC 上的实际执行地址与用户绑定地址不同）
- 🔔 **Top 榜买入推送**：后台每 60 秒检测一次排行榜 Top 用户的买入动态，一旦 **Top 榜内用户买入代币** 立即弹出桌面通知（含名次 #N、买入者、代币、金额/价格/市值/链）；同一条交易不重复推送，同一用户 5 分钟限频一次
  - 可在看板 **⚙ 设置** 中开关推送、调整推送名次范围（Top 1~50，默认 Top 30）；点通知即可直达完整看板
- 🏅 **排行标注**：在搜索代币的 **Top 持有者 / "大家怎么说"发言者 / 用户详情抽屉** 中，只要是排行榜 Top50 内的人，名字旁自动标注金色 **#N** 徽章（N = 实时名次）
- 🔐 **会话自动管理**：浏览 fomo.family 时自动捕获登录态（JWT）；JWT 更新后自动重连实时流
- ⚡ **实时状态指示**：顶栏绿灯 = WebSocket 实时已连接；热门币页有"实时推送中"徽章

### 实时机制说明

| 数据 | 通道 | 更新频率 |
|---|---|---|
| 热门代币 | **WebSocket**（snapshot 全量 + update 增量合并） | 秒级，无需手动刷新 |
| 排行榜 / 信号 / Feed | REST 轮询 | 15 秒 |
| WS 断线 | 指数退避自动重连（1s→15s） | 自动 |

> 扩展的 WebSocket 连接与 Web 端使用同一协议（challenge → challengeResponse{jwt} → subscribe），后台 Service Worker 保持常驻，实时推送驱动页面刷新。

## 安装方法（加载已解压的扩展）

1. 打开 Chrome → 地址栏输入 `chrome://extensions` 回车
2. 打开右上角 **开发者模式** 开关
3. 点击左上角 **加载已解压的扩展程序**
4. 选择本文件夹：`C:\Users\WuHao\Desktop\TraeSolo\fomo_extension`
5. 完成后 Chrome 工具栏会出现 **F** 图标

## 首次使用（获取登录态）

扩展需要你的 FOMO 登录态（Privy JWT）。两种方式任选：

**方式一（推荐，全自动）**
1. 在 Chrome 里打开 [fomo.family](https://fomo.family) 并登录你的账号
2. 点几下排行榜/交易页面（产生 API 请求）
3. 扩展会自动捕获 JWT，点工具栏 **F** 图标即见数据

**方式二（手动粘贴）**
1. 打开看板页（点 **F** 图标 → "打开完整看板"）
2. 点右上角 **⚙ 会话**
3. 把 `session_*.json` 里的 `jwt` 值粘贴进去 → 保存
4. 或用抓包工具（fomo_tools/fomo_capture.py）重新导出一份 session

> JWT 约 30 分钟过期。用**方式一**时，只要你在 Chrome 里偶尔用 fomo.family，扩展会自动刷新；完全不用的话就手动重贴一次。

## 使用

| 入口 | 说明 |
|---|---|
| 工具栏 **F** 图标 | 快捷面板：排行榜 / 信号 / 热门，各看前 10 |
| 快捷面板 → **打开完整看板** | 完整看板页：四页签 + 统计卡片 + 会话管理 |
| 看板页顶部 **搜索框** | 粘贴 代币CA / 钱包地址 / 用户名，回车搜索 |
| 快捷面板顶部 **搜索框** | 快速搜索，回车后自动打开看板并执行搜索 |

> **搜索说明**
> - **代币 CA**（如 Solana 代币地址）会同时展示：代币概览卡片 → 大家怎么说（thesis 观点，最多 15 条，含作者当前持仓与盈亏，评论自动翻译成中文）→ Top 持有者（前 50，含持仓数量/市值/盈亏）→ 最近动态。
> - **钱包地址**会去排行榜（总榜/24h/7d/30d）+ 近期交易者 + **地址反查索引**里匹配 `address`（Solana）、`evmAddress`（EVM）以及交易中出现的实际执行地址。FOMO 没有按地址反查用户的全量接口，所以未命中时只代表"不在近期活跃范围内"，不代表没注册。
> - **用户名**走官方用户搜索（fuzzy-search）。
> - **点击用户卡片**即可打开详情抽屉：含持仓、交易记录、链上活动地址；展开交易记录会静默预取前几笔链上明细，自动把实际执行地址加入反查索引。

```
├── manifest.json        # MV3 清单

├── dashboard.html/css/js # 完整看板页（含搜索栏）
├── popup.html/css/js     # 工具栏快捷面板（含快速搜索）
└── icons/                # 扩展图标
```

## 权限说明

- `webRequest`：观察 fomo.family 页面发出的 API 请求，捕获 Authorization 头（仅读取，不改动）
- `storage`：保存 JWT / 用户 ID / 缓存 / 推送去重记录
- `alarms`：后台心跳（驱动排行榜刷新与 Top 榜买入检测）
- `notifications`：Top 榜买入桌面通知
- 访问 `prod-api.fomo.family` 与 `fomo.family` 两个域名（数据）+ `translate.googleapis.com`（评论翻译）

## 安全提醒

- JWT 就是你的登录凭据，扩展数据存在浏览器本地，**请勿导出分享**
- 仅查看自有数据，遵守 fomo.family 服务条款
